# 🎓 Sistema de Cursos Presenciais — Banco de Dados

Projeto acadêmico desenvolvido para a disciplina de Banco de Dados, com foco na modelagem, implementação e manipulação de um sistema de gerenciamento para cursos presenciais.

---

## 📚 Sobre o Projeto

O sistema foi desenvolvido com o objetivo de simular o funcionamento acadêmico e administrativo de uma instituição de cursos presenciais, permitindo o gerenciamento de:

- 👤 Alunos
- 👨‍🏫 Professores
- 📘 Cursos
- 🏫 Turmas
- 📝 Matrículas
- 💰 Pagamentos
- 📅 Frequência
- 📄 Certificados
- 📚 Disciplinas
- 🚪 Salas

O projeto contempla todas as etapas de desenvolvimento de um banco de dados relacional, desde a modelagem conceitual até a execução de consultas SQL.

---
